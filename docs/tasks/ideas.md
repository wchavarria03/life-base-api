# Tasks (Household/House/TODO) — ideas

Speculative / exploratory directions — not scoped, not committed, no design done yet.
Promote an idea to `enhancements.md` once it's actually going to be built next.

## Due-item notifications

Same cross-cutting gap as Bikes — nothing in life-base pushes/emails when something
becomes due. Would apply here too if ever built app-wide.

## Subtasks / checklist items

Most relevant to TODO: a task with a checklist inside it ("pack for trip" containing
"passport", "charger", ...) rather than everything being a flat top-level task.
Meaningfully bigger than the current flat shape.

## Task templates

A starter set of common household chores ("vacuum living room", "clean bathroom", ...)
to bulk-create from instead of adding each one by hand the first time.

## Location/room tagging for House maintenance

"Kitchen", "Garage", "Roof" as a lightweight tag on House-category tasks, letting a
future UI group by area of the house.

## Before/after photo attachment

Relevant to House maintenance especially — attach a photo when marking a repair/task
complete. Needs file storage, doesn't exist for any domain yet (Social posting doesn't
store images either, it only posts through to Meta).

## Calendar view / ICS export

Export due dates as an `.ics` feed so recurring/one-off tasks show up in an external
calendar app alongside everything else.

## Multi-person assignment

Only relevant if life-base ever becomes multi-user — assign a household task to a
specific person. Not needed for the current single-user setup.
